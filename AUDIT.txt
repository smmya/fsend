fsend 逻辑与安全审查记录
日期：2026-11-17
范围：WorkBuddy fastsend d07ce11 的生产 Go 文件、安装方式与发布流程。

已修复的问题

[高] 接收目录路径越界
原 tar 接收器可创建任意软链接，后续条目或已有软链接目录可将写入导向目标目录之外；serial 也会跟随已有目录链接。
处理：接收路径统一使用 os.Root；拒绝来自网络的链接和特殊条目，源端也拒绝软链接/特殊文件。

[高] Windows 特殊名称和备用数据流
原路径检查只检查开头盘符并仅拦截 NUL，未全面拒绝控制字符、设备名称及 x:stream 等路径。
处理：跨平台拒绝特殊名称、ADS、父目录段，限制长度与深度。末尾点/空格的兼容行为已在 v1.3.0 调整，见下文。

[高] 同名文件覆盖竞态
原 uniquePath 检查之后以 O_TRUNC 打开，两个并发接收可能选中同一个文件名并覆盖已有数据。
处理：使用 O_EXCL 原子预留，重试不同序号，候选耗尽后报错。

[中] 接收资源没有任务上限
持有密钥的对端可声明异常大小或持续发送，长期占用磁盘和连接。
处理：默认 100 GiB/100000 条目；按实际元数据累计额度；serial 实际长度受声明大小约束；增加帧读写超时。

[中] 首次未认证连接结束整个任务
原监听器只接受一个连接，一次错误握手就退出。
处理：拒绝失败握手后继续等待，受原等待期限约束。不宣称能抵御连接洪泛。

[中] 失败退出状态与校验处理
原串行模式部分文件失败仍返回 0；发送端不强制核对某些回执中的 SHA-256；失败输出未清理。
处理：有失败文件最终返回 1；强制核对单文件与最终回执；删除当前失败文件，tar 任务失败时清理本次新文件。

[中] 串行空目录与软链接行为不一致
原串行模式丢失空目录，将软链接目标字符串写成普通文件，与 tar 行为不同。
处理：目录作为明确的零长度目录项传输；两种模式一致拒绝软链接。

[低] 协议与交互健壮性
原底层写入假定一次 Write 完整发送；stream-end 允许非空负载；等待时长可能溢出；监听错误部分无提示；默认 Linux 接收目录依赖高权限。
处理：完整写循环，校验结束帧，校验参数，明确报错，默认目录改为当前目录下 fsend-received。
避免在回执中泄漏接收方实际存储目录；对网络任务名称使用转义显示。
nonce 计数器达到上限时中止会话。

验证范围
新增回归测试覆盖：不安全名称、并发同名创建、已有软链接目录逃逸、归档链接拒绝、失败清理、错误密钥、两种方向和模式的加密传输、大文件/空文件/空目录、错误哈希、超长数据、额度、重放/篡改、HKDF 标准向量与短写。
本地运行 go test、go vet，并在 GitHub Actions 进行 Linux/macOS/Windows 的 race 检查和构建。
Release 流程另验证从 GitHub 下载的 Linux 安装包；Windows 安装器也进行实际下载与哈希校验检查。

剩余边界
这不是第三方安全认证，也没有证明自定义加密协议无任何密码学风险。
必须保护混合密钥、接收目录、发布权限和账号凭据。掌握密钥的对端仍有在限额内写入文件的权限。
接收目录不应与恶意本地用户共享；挂载点、恶意管理员、断电、SIGKILL 与磁盘故障不在完整保护范围内。
不提供事务式提交、断点续传、快照一致性、NAT 穿透、数字签名发布或抗洪泛保证。

v1.3.0 兼容性与交互修复
用户报告大量数据传输后因名称末尾点/空格中断。v1.2.0 将 Windows 命名习惯当成跨平台安全限制，且源目录内的名称未完整预检。
已将安全校验与接收端名称兼容分离：POSIX 保留末尾点/空格；Windows 安全转义，不使用直接删除结尾的方式，以避免文件/目录名称合并。原百分号也转义，防止映射碰撞。
保留路径越界、ADS、控制字符、软链接/特殊文件拒绝，以及 os.Root 与 O_EXCL 防护；补充 Windows 上标数字设备名检查。
新增双模式真实加密传输测试，覆盖带点/空格目录、带点/空格文件、原名与转义名同时存在；Linux/macOS 测试还覆盖源目录真实文件名的保留。
新增向导四种方向、共享输入缓冲、引号路径及 EOF 测试；真实进程验证向导和关闭标准输入的命令行路径。
修复进度行缩短后的尾部残留。界面仍会显示接收文件名转义提示，文件内容校验方式不变。

v1.4.0 文件浏览器与队列检查
添加 tcell 终端文件浏览器，支持多选、跨目录添加、父子去重、队列移除、目录跳转和手动兜底。
浏览器仅枚举当前目录，不递归跟随链接；确认时在可取消的后台任务中执行原有完整文件预检，然后才连接网络。
去重同时用于手动和 --path，使用路径包含关系而非简单字符串前缀，避免把 A-sibling 错当作 A 的内部路径。不同硬链接名称不因共享 inode 被丢弃。
粘贴事件不会触发快捷键；显示控制字符经过转义；窗口缩小或长路径不会越界绘制。取消与普通中断恢复终端状态。
新增依赖锁定版本并保留模块校验；各发布包附 THIRD_PARTY_NOTICES.txt。浏览器依赖不会引入运行时外部安装要求。
新增测试覆盖跨目录、父子选择顺序、路径别名、特殊文件拒绝、队列删除、预检取消、手动切换、粘贴保护和窗口尺寸。
原有命令行、管道输入、两种传输模式与正反向连接继续进行回归验证；Actions 另执行真实 POSIX 伪终端选取和传输测试。

v1.4.1 按键与取消行为
Esc 调整为返回上级/返回浏览，保留左箭头；根目录不因 Esc 退出。Y/y 与空格只勾选或取消当前项，最终发送仍使用 F10/Ctrl+S。
取消后台读取/预检时保留选择，并通过任务序号拒绝过期结果，防止取消后旧结果导致发送或界面回退。
新增回归覆盖大小写 Y、空格、Esc 上级、左箭头、队列返回、输入框取消和最终确认后队列保持一致。
